# Luciano Galvão

Software engineer focused on front-end, based in São Paulo, Brazil. I work at **Intelbras**, where I'm a technical lead on the front-end team: I help set code standards, review solutions and work with the Cloud, Mobile and Desktop teams on cross-platform products.

Day to day I build web applications with **React**, **Next.js** and **TypeScript**, and I care a lot about what keeps them healthy over time: tests, static analysis, security and automated quality gates in CI.
